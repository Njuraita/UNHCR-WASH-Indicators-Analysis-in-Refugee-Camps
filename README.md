# UNHCR-WASH-Indicators-Analysis-in-Refugee-Camps

An exploratory data analysis project examining Water, Sanitation and Hygiene (WASH) indicators in refugee settings across the world using publicly available UNHCR data. The project aims to explore geographical distribution, identify patterns in WASH service provision, and generate insights that can support humanitarian Monitoring, Evaluation and Learning (MEL), programme monitoring and evidence-based decision-making.

## About the Project

Access to safe water, adequate sanitation and proper hygiene services is essential for the health, dignity and protection of refugees and displaced populations.

This project uses publicly available data from the United Nations High Commissioner for Refugees (UNHCR) to explore WASH-related indicators across refugee settings.

Through data cleaning, exploration, transformation and visualisation, the project seeks to examine patterns in humanitarian WASH service provision and demonstrate how data analytics can contribute to monitoring programme performance and informing humanitarian interventions.

## Objectives

The project aims to:

- Explore WASH-related indicators in refugee settings across different countries.
- Examine the geographical distribution of WASH-related records.
- Identify patterns and variations in WASH service indicators.
- Perform data cleaning, validation and transformation to improve data quality.
- Generate meaningful insights to support humanitarian Monitoring, Evaluation and Learning (MEL).
- Demonstrate the application of Python and data analytics in humanitarian and development contexts.

## Data Source

**Organisation:** United Nations High Commissioner for Refugees (UNHCR).

**Source:** UNHCR Operational Data Portal / publicly available UNHCR datasets.

The project uses publicly available humanitarian data. Data preparation and analysis are conducted for educational, research and portfolio demonstration purposes.

## 💻 Getting Started

To obtain a local copy and explore the project, follow the instructions below.

### Prerequisites

You will need:

- Python 3.x
- Git
- Visual Studio Code or Jupyter Notebook
- Basic knowledge of Python and data analysis

### Setup

Clone this repository to your local machine:

```bash
git clone https://github.com/Njuraita/UNHCR-WASH-Indicators-Analysis-in-Refugee-Camps.git 
Navigate to the project directory:

```bash
cd UNHCR-WASH-Indicators-Analysis-in-Refugee-Camps
```

### Installation

Install the required Python libraries:

```bash
pip install pandas numpy matplotlib seaborn pycountry-convert jupyter
```

## Usage

1. Clone the repository to your local machine.
2. Open the project folder in Visual Studio Code or Jupyter Notebook.
3. Install the required Python libraries.
4. Open the main analysis notebook (`main.ipynb`).
5. Execute the notebook cells sequentially to explore the data preparation, cleaning, transformation and analysis processes.

The project is being developed progressively, with further analysis and visualisations added as the investigation advances.
